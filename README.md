## How to Set Up the Post-Purchase Email in Gumroad

1. Log in to [Gumroad](https://gumroad.com) and open your product (`$29 book`).
2. Go to **Edit product → Receipt** (or **Thank You** email section).
3. Copy the content from [`post-purchase-email.md`](./post-purchase-email.md) and paste it in.
4. Use Gumroad's `[First Name]` merge tag so each email is personalized.
5. Save and publish.

Every buyer will now be automatically directed to [aifordjsglobal.com](https://aifordjsglobal.com) the moment they purchase.
